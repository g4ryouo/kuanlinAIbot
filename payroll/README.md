# 寬林薪資計算（網頁版）

```bash
pip install -r requirements.txt
python app.py        # 開 http://localhost:5000 ，手機同網段也可用
python -m pytest -q  # 規則驗算（以 2026/10 實發薪資條為基準）
```

## 使用流程
1. Google Sheet「[寬林] 員工打卡紀錄」→ 檔案 → 下載 → .xlsx
2. 網頁選月份、上傳 → 自動帶入每人的天數、加班、請假、午餐天數 → 可直接修改，右側金額即時重算
3. 「下載薪資條 Excel」→ 依 `templates/薪資條範本.xlsx`（你的 v5 格式、標楷體、兩聯）填好，會計可直接列印

## 規則（皆來自 2026/6、8、9、10 月薪資條與 LINE 對話）
- 一律用 **LINE ID** 對應員工（顯示名稱會改，例如「紅色」）
- **夜工**：前一天有上班卡、沒下班卡且 15:00 後上班，隔天凌晨的「上班」其實是下班卡 → 算 2 天班、1 餐
- **午餐津貼**：有完整上下班打卡才給 $150/天；缺下班卡、請假、颱風假不給；$3,000 以內免稅、超過算應稅。王永杰/莊岳倫另有固定 $2,000
- **加班費**：時薪=本薪÷30÷8（進位），平日前 N 小時 ×1.33、其後 ×1.66；假日加班依人不同（見 config.json `holiday_ot_mult`）
- **病假**半薪、**事假**全薪，並按 獎金÷30 扣全勤獎金；特休不扣
- **楊東翰**：固定 5 萬，平日缺勤以假日出勤 1:1 補，補不足才扣（本薪÷當月工作天數）、多出的假日出勤算點工；3、8 月半年獎金
- **張欽煌**：日薪 × 出勤天數
- 每年更新 `config.json` 的 `holidays`（國定假日/補假）；颱風假填 `typhoon_dates`

## 已知限制
- 午餐天數、國定假日要靠 config 與打卡資料，網頁上都能手動改
- 範本沒有的欄位（如 8 月的「代墊款項」）需先在範本新增欄位標題，名稱相同才會印出
- 尚未寫回 Google Sheet 的「旭寶計算」V 記號（網頁只顯示哪些已打 V）
